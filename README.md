# ❤️ Heart Disease Prediction System

A Machine Learning-based web application that predicts the likelihood of heart disease based on a patient's medical information. The project demonstrates a complete end-to-end machine learning workflow, from data preprocessing and model training to deployment with Streamlit.

---

## 📌 Project Overview

Heart disease is one of the leading causes of death worldwide. Early prediction can help support timely medical evaluation. This project uses a supervised machine learning model trained on heart disease data to estimate whether a patient is likely to have heart disease based on clinical features.

---

## ✨ Features

- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Feature scaling
- Machine Learning model training
- Model evaluation
- Interactive Streamlit web application
- Real-time predictions based on user input
- Saved model for deployment using Pickle/Joblib

---
## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib
- Joblib / Pickle

---
## 📊 Dataset

The dataset contains patient health information such as:

- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Resting ECG
- Maximum Heart Rate
- Exercise-Induced Angina
- Oldpeak
- ST Slope
- Target (Heart Disease)

---
## 📈 Machine Learning Workflow

1. Load dataset
2. Data cleaning and preprocessing
3. Exploratory Data Analysis
4. Feature scaling
5. Train-test split
6. Model training
7. Model evaluation
8. Save trained model
9. Build Streamlit interface
10. Deploy prediction system

---
## ▶️ Run the Application

Start the Streamlit application:

```bash
streamlit run app.py
```
The application will open in your default browser.
